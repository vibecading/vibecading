How it works
Every letter A–Z adds its own shape. The interactive keyboard shows the map: hold a physical key to light it, or tap a key on screen. Holding a key adds one shape. QWERTY follows the physical rows; Compact fits touch screens. Original digit shortcuts 1–6 still work. ? reveals a formula; H is now Hex prism. Enter builds the command
Backspace removes the last queued shape; Escape clears the queue. An empty draft leaves the scene empty. Restore build brings back the last submitted build; Edit build recalls its command for editing
Start at B2. Left/Right move along X (columns A–C), Up/Down along Y (rows 1–3). Select a tile, stack, or map cell directly. Free build accepts up to 16 shapes, with SVG export. Try Blueprints, Spatial, Parts kit or the daily blueprint. Kits disable all shapes absent from their inventory; removing a queued part returns it
Campaign hints cost 50 points and limit stars. Daily uses the date's UTC seed and scores accuracy and economical shape input; time and movement are free. Sessions and records save on this device. Copy or download daily result cards to share yourself
